🚀 Cara Langsung Menjadikan Google Docs (10 Detik)

  1. Buka Google Drive (drive.google.com) di browser kamu.
  2. Tarik (drag-and-drop) file Dokumentasi_Skema_Database_Mission_1.docx yang ada di folder ini ke Google Drive kamu.
  3. Klik dua kali file yang baru di-upload di Google Drive. Google Docs akan langsung membukanya dalam format Google Docs resmi dengan seluruh tabel, warna header, dan format yang rapi sempurna!
  4. Klik tombol Bagikan (Share) di pojok kanan atas Google Docs untuk mengambil link pengumpulan tugas.
